# aiogram + PostgreSQL Example

Shembull boti aiogram me PostgreSQL — menaxhim përdoruesish dhe të dhëna në databazë relacionale.

`Python` `aiogram` `PostgreSQL`

## 🚀 Live Demo
Hape **`index.html`** në browser — demo-ja ekzekutohet direkt, pa instalime.
Nëse repo është publikuar me GitHub Pages: `https://erionnezha.github.io/Aiogram-Postgres-Example/`

## 📝 Kodi Burim
Kodi i plotë është në dosjen [`original/`](original/) dhe shfaqet krahas demo-s live në `index.html`.

> ⚠️ File-i origjinal `.env` përmbante kredenciale reale dhe u hoq për siguri — përdor `.env.dist` si shabllon.

## ▶️ Ekzekutimi origjinal
Kopjo .env.dist → .env me kredencialet e tua, `pip install -r requirements.txt`, `python app.py`.
